# 当前实验结果与投稿证据说明

更新日期：2026-10-08。依据最新 v8 稿件和 2026-10-01 本地实验归档核对。
本次没有重新训练或重新评估。以下 AP 数值均以百分数显示，差值单位为百分点。

## 1. R-LiViT 主实验：固定 held-out test

2,400 帧按序列划分为 1,440 / 480 / 480（train/dev/test），对应 120 / 40 / 40 个互不相交的序列。
测试集包含 312 白天帧、168 夜间帧。checkpoint 依据 dev 选择，主表依据
`results/eval_*.json` 的独立 COCO 评估，而非 `summary_sq.json` 的训练框架评估。

| 模型 | mAP50：s0 / s1 / s2 | 均值 | mAP50–95：s0 / s1 / s2 | 均值 |
|---|---|---|---|---|
| Concat | 60.88 / 59.83 / 57.43 | 59.38 | 38.78 / 38.95 / 37.32 | 38.35 |
| GBF | 61.13 / 59.44 / 58.77 | 59.78 | 39.78 / 38.55 / 39.46 | 39.26 |
| GSW | 61.54 / 58.96 / 60.75 | 60.42 | 39.67 / 38.93 / 39.61 | 39.40 |

GSW 的三种子均值最高，但逐种子、逐指标排序不一致，不能写“全部种子两个指标全胜”。
GBF−Concat 的平均变化为 +0.40 mAP50、+0.91 mAP50–95；三种子仅支持描述性比较。
TBF 只有 seed 0：59.67 / 38.65，不能与三种子均值直接比较稳定性。

### 夜间 mAP50

| 模型 | s0 / s1 / s2 | 均值 |
|---|---|---|
| Concat | 47.88 / 47.77 / 39.32 | 44.99 |
| GBF | 51.04 / 41.85 / 42.97 | 45.29 |
| GSW | 48.49 / 44.94 / 49.63 | 47.68 |

GBF−Concat 夜间差值约 +3.2 / −5.9 / +3.7，平均约 +0.3；种子波动约 5 个百分点。
不能据此声称稳定的夜间优势。

## 2. 重采样统计：已发现需要复核的问题

`bootstrap_seq.json` 保存 AP50 3,000 次、AP 1,000 次序列重采样结果，模型固定为 seed 0。
但历史程序用 `set(sample)` 筛选帧，重复抽到的序列会被去重，没有保留有放回抽样的次数。
因此下列数值是原始诊断记录，不应直接称为标准 bootstrap 置信区间或显著性证据。
需要修正重采样实现并重新计算，再修改论文对应正文及 Fig. 4 / Fig. 6。

| 对比 | 记录的 ΔAP50 均值 [百分位上下界] | 记录的 ΔAP 均值 [百分位上下界] |
|---|---|---|
| concat_vs_gbf_full | +0.37 [-0.83, +1.70] | +1.03 [+0.17, +2.02] |
| concat_vs_gbf_night | +3.98 [+0.19, +9.13] | +3.87 [+0.69, +7.78] |
| concat_vs_gsw_full | +0.56 [-0.71, +1.73] | +0.84 [+0.07, +1.64] |
| depth_4ch_vs_5ch | +1.82 [-2.60, +6.91] | +0.52 [-1.33, +2.65] |

固定模型的序列重采样即使修正，也不能代表训练种子的随机性。
这些重采样均值与整份测试集直接计算的差值不是同一个估计量。

## 3. 晚融合与定性记录

同配方 RGB-only + thermal-only 晚融合，seed 0/1 夜间 mAP50 为 54.32 / 57.34，
均值 55.83，比匹配种子的 GSW 高约 9.1 个百分点，模型参数约为单模型的两倍。
这是本研究中的参考对照，不能称为普遍的“夜间精度上限”。
来源：`eval_late_*.json`、`eff_v2.json`。

夜间 seed-0 定性匹配采用 confidence=0.25、IoU=0.5、类别一致一对一匹配：
144 improved、70 degraded、1,749 both-detected、613 neither-detected。
这些是阈值相关的目标状态统计，不是 AP 变化或门控的因果效果。
来源：`qual_report.json`、`qual_breakdown.json`。

## 4. 投影深度：单独划分的探索性子集

782 帧划分为 473 / 155 / 154，测试含 13 个序列。标定为 label-informed，
71 个序列对达到拟合中位残差 ≤60 px；这不是独立几何精度验证。
填充前深度覆盖率中位数 1.78%，同步时间差中位数 19.8 ms、最大 40 ms。

| 配置 | seed 0 / 1 / 2 mAP50 |
|---|---|
| 4ch Concat | 37.73 / 39.42 / 38.80 |
| 5ch Concat | 39.02 / 38.60 / 39.83 |
| 匹配种子差值 | +1.29 / −0.82 / +1.03（均值 +0.50） |

seed 0 同子集 4ch GBF=39.33、5ch 等权 TBF=39.98、5ch 门控 GBF=39.49。
深度增益方向混合，不能声称一般性三模态优越。
来源：`msq_summary.json`、`splits/rlivit_multi_sq_build_stats.json`、`data/calib_per_seq.json`。

## 5. LLVIP：单独重新训练

11,025 train / 1,000 dev（划分 seed 42）/ 完整 3,463 test；已恢复早期漏掉的 790 对。

| 配置 | test mAP50 s0 / s1（均值） | test mAP50–95 s0 / s1（均值） |
|---|---|---|
| Concat | 94.86 / 95.60（95.23） | 58.43 / 59.14（58.79） |
| GBF | 94.61 / 95.56（95.09） | 58.81 / 60.74（59.78） |

GBF−Concat 的均值差为 −0.145 mAP50、+0.99 mAP50–95：结论依指标而变。
不能声称统计等效、“打平”、数据集饱和或零样本迁移。
来源：`llvip_summary.json`、`splits/llvip_dev_manifest.csv`。
